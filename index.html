Buka kampil

Lupa password? Pulihkan dengan kode pemulihan

Tanpa password dan tanpa kode pemulihan, isi kampil tidak bisa dibuka. Jalan terakhir: hapus kampil ini dan mulai dari awal, atau pulihkan dari file backup.

  • Enkripsi AES-256-GCM (Web Crypto) dengan kunci turunan PBKDF2 250.000 putaran. Isi Kampil tidak pernah dikirim dalam bentuk teks biasa ke server mana pun — yang diunggah ke Google Drive hanyalah file .kampil terenkripsi, dan hanya bila backup Drive tersambung.
  • Terkunci otomatis setelah 5 menit tanpa aktivitas. Password yang disalin terhapus sendiri dari clipboard setelah 20 detik.
  • Backup berupa file .kampil terenkripsi — aman disimpan di mana saja, termasuk Google Drive, karena tanpa master password isinya tidak terbaca.
  • Sinkronisasi Drive (opsional): bila diaktifkan dari panel Backup & Drive, satu file sinkron terenkripsi kampil-sync.kampil di folder Kampil di Drive membuat isi brankas saling mengikuti antar perangkat yang memakai master password yang sama — tanpa ekspor-impor manual lagi.
  • Kode pemulihan dibuat sekali saat brankas dibuat dan hanya disimpan dalam bentuk terenkripsi — ia bisa membuka brankas dan mengganti master password tanpa menghapus isi, bila suatu saat kamu lupa password.

Pasang Kampil sebagai aplikasi

Deploy sendiri lewat GitHub Pages

Kalau pilihan Instal belum muncul dan yang ada hanya Buat pintasan, repo GitHub-nya belum lengkap. Unduh paket lengkap ini, lalu unggah seluruh isinya ke repo — jangan hanya index.html saja.

  • index.html — aplikasi Kampil (sudah menunjuk manifest di root)
  • manifest.webmanifest — di root, syarat Chrome untuk instalasi
  • sw.js — service worker di root, sejajar index.html
  • assets/ — ikon 192, 512, maskable, dan apple-touch-icon
  • README.md — deskripsi, cara instal, backup, dan kode pemulihan

Setelah diunggah: aktifkan Settings → Pages di GitHub, buka alamat github.io-nya langsung di Chrome Android, lalu pilih Instal aplikasi.

Sinkronisasi antar perangkat (lewat Drive)

Dengan sinkronisasi aktif, Kampil menaruh satu file sinkron terenkripsi bernama kampil-sync.kampil di folder Kampil yang sama di Drive, dan menimpanya setiap ada perubahan. Perangkat lain yang membuka Kampil dengan master password yang sama dan Drive tersambung akan mengambil versi terbaru itu secara otomatis — tidak perlu ekspor-impor manual lagi.

Drive hanya menyimpan file terkunci: isi brankas tidak pernah dikirim dalam bentuk teks biasa. Yang terlihat di luar enkripsi hanya metadata kecil (nomor versi berupa waktu perubahan dan ID acak perangkat penulis).

Status sinkronisasiNonaktif
Perangkat ini—

Syarat: master password sama persis di semua perangkat, akun Google Drive yang sama tersambung di tiap perangkat, dan ada internet saat sinkron berjalan. Sinkronisasi hanya berjalan saat Kampil terbuka / tidak terkunci.

Menyiapkan perangkat kedua: 1) Buka Kampil dari alamat yang sama, buat brankas baru dengan master password yang sama (boleh masih kosong). 2) Sambungkan Drive yang sama di panel ini. 3) Aktifkan sinkronisasi — isi dari Drive akan diambil mengisi brankas kosong itu. Setelah itu semua perangkat saling mengikuti.

Konflik: bila dua perangkat mengubah isi sebelum sempat sinkron, versi yang terakhir diubah yang dipakai, dan versi yang kalah tidak hilang — disimpan sebagai file kampil-konflik-… .kampil di folder Kampil di Drive, bisa dibuka lewat Impor file .kampil. Backup berkala biasa di bawah tetap berjalan sebagai cadangan tambahan.

Belum punya Client ID? Buat sekali saja, gratis:

  1. Buka console.cloud.google.com → buat project baru (mis. “Kampil”).
  2. Aktifkan Google Drive API (APIs & Services → Library).
  3. Di OAuth consent screen pilih External, isi nama aplikasi, lalu tambahkan emailmu sebagai test user.
  4. Di Credentials → Create Credentials → OAuth client ID → Web application, tambahkan alamat halaman ini di Authorized JavaScript origins, lalu salin Client ID-nya ke kolom di atas.

Paket lengkap untuk GitHub Pages

Unduh satu ZIP berisi semua file yang Chrome butuhkan untuk menampilkan tombol Instal (bukan hanya pintasan):

  • index.html di root
  • manifest.webmanifest di root
  • sw.js di root (sejajar index.html)
  • assets/ berisi ikon 192, 512, maskable, dan apple-touch-icon
  • README.md dengan panduan instal & backup lengkap

Ekstrak ZIP ini, lalu unggah seluruh isinya ke root repo GitHub kamu dan aktifkan GitHub Pages. Mengunggah index.html saja tidak cukup — tanpa manifest, ikon, dan sw.js di posisi yang benar, Chrome hanya menawarkan pintasan.

Agar Chrome Android menampilkan pilihan “Instal” (bukan hanya “Buat pintasan”), repo GitHub Pages harus berisi seluruh isi ZIP terbaru, bukan index.html saja: file sw.js di root repo (sejajar index.html — posisi ini wajib agar service worker bisa mengontrol halaman utama), file manifest.webmanifest juga di root repo (sejajar index.html), dan ikon-ikon di folder assets/ adalah syarat teknis Chrome untuk instalasi. Buka alamat github.io-nya langsung di Chrome (bukan dari pratinjau di dalam aplikasi lain), tunggu beberapa detik, lalu menu ⋮ → “Instal aplikasi”. Pintasan lama yang terlanjur dibuat bisa dihapus — pintasan hanya membuka Chrome, sedangkan aplikasi terinstal berjalan layar penuh dari ikonnya sendiri. Play Store tetap membutuhkan akun Google Play Developer dan pembungkus TWA, bisa menyusul.
