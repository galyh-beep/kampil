# Kampil — Brankas Info Akses

Aplikasi PWA lokal terenkripsi untuk Kontak, Rekening, Akun Login, Kode, dan Catatan.

## Deploy ke GitHub Pages
1. Buat repo baru di GitHub (misal: kampil)
2. Upload file index.html ini ke repo
3. Settings > Pages > Deploy from branch > main
4. Buka alamat GitHub Pages-mu, lalu di Android Chrome: menu titik tiga > Tambahkan ke layar utama / Install app

## Catatan penting
- Data hanya tersimpan terenkripsi di perangkat (IndexedDB), bukan di GitHub.
- Backup otomatis ke Google Drive butuh OAuth Client ID sendiri — lihat panel Backup & Drive di aplikasi.
- Jangan pernah membagikan file .kampil atau master password ke siapa pun.
